# softmax 到底用在哪

2026-11-26 · W1 · 读 3B1B + 自问自答

## 一句话

softmax 不是「算概率的公式」，是**把一组分数变成一组加起来等于 1 的权重**的工具。凡是需要回答「这 N 个东西各占多少比例」的地方，都会用到它。

## 机制（手算一遍）

给定三个分数 `z = [2, 1, 0]`：

1. 取指数：`[e², e¹, e⁰] = [7.39, 2.72, 1.00]`
2. 求和：`7.39 + 2.72 + 1.00 = 11.11`
3. 各自除以总和：`[0.665, 0.245, 0.090]`
4. 验算：`0.665 + 0.245 + 0.090 = 1.000`

原来差 1 分的两个分数，最后差了 2.7 倍——softmax 会**放大差距**，但结果永远落在 (0, 1) 里。

## 三处用处

### ① Attention 里（主战场）

```
Q: n×d,  K: n×d
S = Q·Kᵀ        →  n×n    每个格子是一个分数
A = softmax(S)  →  n×n    按行做，每行加起来 = 1
O = A·V         →  n×d
```

关键是**按行**：第 i 行是「第 i 个 token 把注意力分给其他所有 token 的比例表」。每个 token 只有 1 份注意力预算，softmax 决定怎么分出去。

不归一化会怎样？`A·V` 的结果会随 n 增大而膨胀，叠十几层就爆了。

### ② 输出层

最后一层得到词表大小的 logits（比如 5 万个分数）→ softmax → 5 万个概率，加起来是 1。**这里才是字面意义上的「下一个词是哪个」的概率。**

### ③ MoE 路由 / 多分类

MoE 的 gate 给每个 expert 打分，softmax 决定「这个 token 分多少比例给哪个 expert」。

## 为什么是 exp，不是直接除以总和

- 分数可能是**负数**（attention 的 score 就有负的），直接除会出现负权重
- exp 恒正、单调、可导
- 它把差距拉开，让「明显更该被注意的」更突出

## 为什么 attention 里还要除以 √d_k

分数整体偏大时，softmax 会变得极尖（几乎 one-hot），梯度趋近于零。先除以 √d_k 把分数压回正常范围，再 softmax——这就是论文里那个 `√d_k` 的来历。

## 它和 CNN 的卷积是什么关系

底层是同一个动作：**乘加**。一个卷积核在 3×3 窗口上做的，就是一个 9 维点积。

|  | 权重从哪来 | 看多大范围 | 是否共享 |
| :--- | :--- | :--- | :--- |
| 全连接 / MLP | 训练学出来，固定 | 整个输入 | 不共享 |
| CNN | 训练学出来，一个小核 | 局部窗口 | **共享**，同一个核滑过整张图 |
| Attention | **每次从数据当场算**（Q·K） | 全局，任意两个位置 | 每个位置一套 |

更本质的共同点：**都在用点积问「有多像」**。

- 卷积核是一个学好的模式模板（比如边缘检测器），点积衡量「这块图像有多像这个模板」
- attention 的 Q·K 衡量「第 i 个 token 有多需要第 j 个 token」

区别是：CNN 的模板是**训练好的、固定的**；attention 的模板是**每个 token 现场生成的**。

一个直接后果：CNN 只看 3×3 的局部，要靠堆层扩大视野；attention 一层就能让任意两个位置直接相连。这就是论文标题 *Attention Is All You Need* 的字面意思。
